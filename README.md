# Diwali-Sales-Analysis

Exploratory Data Analysis (EDA) project using Python (NumPy, Pandas, Matplotlib, Seaborn) and Minitab.

## Objectives
- Analyze Diwali sales data
- Identify customer buying patterns
- Compare Python vs Minitab analysis

## Tools Used
- Python (Jupyter Notebook)
- Minitab Statistical Software
